## Tentang Aplikasi
Aplikasi web sederhana untuk mengelola kategori buku di perpustakaan.

## Fitur
- Lihat daftar kategori
- Tambah kategori baru
- Edit kategori
- Hapus kategori

## Cara Install
1. Clone repo ini
2. Import file `database/database_backup.sql` ke phpMyAdmin
3. Sesuaikan nama database di `config/database.php`
4. Jalankan lewat XAMPP di folder `htdocs`
